Dabra (DabraData) provides a Brazilian data intelligence platform offering REST API access to official and private sources for CPF and CNPJ queries, KYC, compliance, judicial processes, and international sanctions. Prices per query are published before account creation, with a prepaid credit model, no monthly fees, and real‑time usage dashboard. The service aggregates public government data and authorized private providers, enabling due‑diligence, risk assessment, and AI‑assistant integration via the Model Context Protocol (MCP).

**Areas:** Data · API · Brazil · KYC · Compliance
